# shorts-caption-templates

Six vertical (1080×1920) Shorts editing templates (layout, caption style and position, hook, zoom rhythm, music level), plus one script that applies a template to a clip and its word timestamps.

## Use the bundled copy
This folder is already included in video-workflow-starter. No Git, clone, repository access, or GitHub authorization is required. Install the starter's `packaging` dependencies and use `workflow.py captions` from the package root. See [the integration guide](../../references/caption-packaging.md).

The starter integration preserves approved text and disables automatic camera movement. Its production rules take precedence over the original template defaults below. Updates arrive in a new starter ZIP.

## Quick start
```bash
bash tests/run_tests.sh            # renders all templates on synthetic footage → tests/out/
python3 scripts/apply_template.py --template specs/B_word_highlight_quote.json \
  --video my_clip.mp4 --words my_clip_words.json --lang en --out out/my_clip_B.mp4 --preview 1.5
```
See `SKILL.md` for template choice, all flags, hard rules and the verification checklist.

## Layout
| Path | What |
|---|---|
| `SKILL.md` | Agent instructions |
| `specs/*.json` | 6 template specs (A–F); generated by `scripts/make_specs.py` |
| `ass/*.ass` | ASS style headers per template × language (id / mn / zh) |
| `scripts/apply_template.py` | Renderer (ffmpeg + libass) |
| `scripts/make_specs.py` | Source of truth for the specs |
| `data/ref_stats.json` | Numeric rhythm and loudness stats measured from public reference Shorts (no media included) |
| `fonts/` | Static OFL font instances + licenses (`make_static.py` shows how they were made) |
| `tests/` | Synthetic-input test suite and preview generator |
| `previews/` | One frame per template, rendered on synthetic footage (示意, not a finished video) |

## Notes
- The reference numbers (shot length, loudness, music-bed gap) are measurements. Caption animations and zoom amounts were inferred from frames and are marked 推断 in the specs.
- Example copy in `specs` for Indonesian and Mongolian is marked 待译者核对 (to be checked by a translator).
