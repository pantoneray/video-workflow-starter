# 选文、译审与成片规则

## 选文和画面分开管理

按用户给定的本地资料范围及主题检索。热点选题先核查当前事件、来源、日期和受众适用性；长期关心话题不必伪装成实时热点。先确定话题与原文含义是否匹配，再选择自然连续的画面。视频原声的观点不是画面选片的唯一依据，画面不能冒充文案出处。

`source` 提供关键词候选、逐字原文、文件哈希和位置；语义判断由 Agent 阅读上下文完成。包内没有自动热点雷达或语义向量索引。跨段重组按用户明确范围执行：保留每句原文、章节/行页、上下文、重组顺序和逐句映射；向用户展示完整稿件并确认，不删除否定和限定语，不把重组文字称为原书连续段落。

保存 `copy-vN.json` 与 `source-map-vN.json`：分别列出文字原文、摘录、逐句出处和画面文件、哈希、入出点。每句注明讲者原话/翻译、提问者原话/翻译、转述或编辑连接语；新写连接语不能借真人口型伪装成其原话。书籍段落没有原视频轴时填 null；预估配音轴不能冒充原片轴。多段资料由 Agent 整理上述映射，本包检索脚本不自动证明重组忠实性。

## 初译、独立复核和人工改稿

默认由 Codex 根据获批原文与术语写初译文件；用 `review create --draft <初译.txt> --draft-author Codex` 接入已有版本流程。Gemini 先仅看原文独立翻译，再比较初译与独立译文；盲回译只看目标语。保存真实调用结果及版本，不能以 Codex 自审冒充独立模型调用。用户指定其他初译方式时仍可用原有模型初译入口。

口播不能用 `()` 或 `（）` 插入解释。必要含义写成可直接念出的自然目标语；仅供查阅的释义放在术语表或审稿备注。初译、独立译、送审、HeyGen 草稿 SRT 和成片 SRT 都检查这一点。发现需改字时走修订和审核流程，不能只在字幕中删掉括号文字而保留原声音。

用户可主动改稿、换选题或换片；只重做受影响的步骤。保留当前获批全文与逐条意见回应。送审结果必须标清已确认、待改或未知，不靠回译相似度宣称绝对准确。括号解释属于语义复核规则，当前脚本提示模型检查，尚无可靠的自动语义拦截。

## HeyGen 前后

进入 HeyGen 前选定该语种的语速参考：用户数值、注明依据的平均值或音频样本。计算有效字符、合理分句、时长和预估 SRT；文案过长就换合适视频或返修文案，不能加速、循环或冻结硬凑。

使用包内 CLI OAuth 上传视频和获批 SRT，创建 Proofread 草稿并回读。用户网页试听、调整后按当前版本继续，改字不自动重建草稿。Precision 和动态时长按明确配置使用；远端延长过时长或改变动作时检查实际结果，不用后期变速补救。

## 本地包装与验收

- 默认输出全屏 9:16、1080×1920；预剪片段保留源片规格，二者分开。
- 固定裁切框优先。头部安全时锁定构图；只有头部即将出框时才最小幅度平滑调整，到位保持。检测框波动和留白变化不触发反复跟随。没有安全方案则复核或换素材。
- 不拉伸人物，不定格、快进、放慢或循环补时长。重置 PTS 不等同变速，按实际播放检查。
- 最终字幕绑定真实成片音频。逐词动效须有实测词级时间戳，保留获批稿大小写、标点和全部限定语；没有词级数据时使用句级字幕，不按字符均分假造词级对齐。
- 字幕正文和底板水平居中，1080 宽时 x=540；用左右对称限宽、断行处理平台按钮区。单行、多行和动效均遵守；品牌标识按其版式。
- 字幕、阴影、底板、贴纸和动效全程避开面部。逐条核对头部、手机可读性、字体字形、行数、停留时间和平台遮挡；模板字号与安全区是候选值，不能代替成片检查。
- 使用[包内字幕模板](../tools/shorts-caption-templates/SKILL.md)，执行方式见[字幕包装说明](caption-packaging.md)。基础包默认保留原声，配乐与素材须有可用许可。
- 静音时段检查讲话式嘴部动作。仅在末字、字幕和自然停顿之后有安全切点时剪异常尾部，再检查；中段、无法保住原句或低置信情况标时间点人工复核。
- 技术检查包括完整解码、音轨、时长/PTS、字幕完整性和响度；实际观看检查口型、手势、切口、构图及连续性。脚本退出成功不等于视觉验收通过。

根据当前文案生成封面文字、标题和简介，保留用户明确输入。用户可继续用自己的剪辑软件；最终文件、封面和发布资料确认后，沿用 YouTube 私密上传流程。成片通过不等于获准公开发布。
