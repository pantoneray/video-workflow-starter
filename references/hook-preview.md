# 包装阶段钩子预览

与文案前置方案二选一。只在正文没有采用文案前置钩子时使用 `hook-preview`，明确传 `--body-hook-mode none`。本入口不生成声音、不改译稿、不上传；只把已有模板成片中的完整一句复制到片头，接0.2秒黑场，再接完整原成片。该短切过渡须试听确认，不自动判定自然。

```bash
python workflow.py hook-preview --video ./package/final.mp4 --words ./aligned.json --approved ./approved.txt --packaging-receipt ./package/receipt.json --sentence-index 1 --body-hook-mode none --out ./preview-v1
```

默认仅生成计划。检查完整句和时长后，换新的输出目录并加 `--render` 生成本地待审MP4；不得覆盖旧目录。句编号从0开始，沿用hook-copy的完整句分割。输入须为既有模板渲染成片、对应实际音频对齐文件、审定文本和渲染回执；三者SHA必须匹配。回执只证明包装技术结果，不代替用户审批。

如果一句话边界落在对齐单元内部，则拒绝剪切，要求更精确的实际音频对齐。完整句目标约3秒；总时长按重复句、0.2秒过渡、完整正文相加，目标30–45秒。超出目标仍可生成标明风险的待审预览，但不能当作符合时长要求的成片。不要截去限定语或改速凑时长。

字幕直接保留已由Skill模板烧录的画面，未使用替代字幕渲染；预览部分字幕随原画面同步。外部SRT不会自动沿用旧时间轴。导出使用FFmpeg，核对音轨、9:16画幅、实际时长、完整解码及输入未变；失败写failure.json，残留MP4不得交付。输出receipt要求新的T4版本审核，旧成片批准不得沿用。

当前限制：不自动判断吸引力/语义独立，不自动选句；完整句与音频边界仍须听看。未自动生成可播放的本地T4页面或接入生产执行器。当前为独立可选预览阶段；没有授予任何付费生成或上传权限。

输入边界：模板渲染产物可能仍是尾剪前的中间文件；不要把中间文件误当最终成片。末句后超过1秒会提示核对尾剪。技术解码通过不等于自然度或时长已获批准。

## 可选最终裁切回执关联
现在支持同时提供 `--finalization-receipt` 与 `--finalization-manifest`，核验最终视频SHA、原manifest SHA、原视频/模板输出/审定文本关联、逐条SRT与短语对齐一致、实际尾剪时长。原回执保持不改；显式替换音轨的旧任务先拒绝，须补新的实际对齐绑定。该兼容入口针对既有尾剪回执结构，不宣称任意剪辑器通用。
维护方交接记录报告：真实样本改用最终23.936秒成片后，预览32.636秒，完整解码且输入未变；4帧查看证实前置句/黑场/正文衔接顺序。前置完整句仍8.5秒，未满足约3秒目标；听感和语义未获用户批准。该技术验证不代表样片已通过T4，也不自动接入生产。

本打包轮仅复验合成FFmpeg样本，不纳入私人真实视频、源文或执行器脚本，也不将上述维护方记录当作当前用户批准。
