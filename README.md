# Video Workflow Starter

供团队成员在自己的 Mac 与 Codex 中使用的视频工作流 Skill：批量切片、资料选文与译审、HeyGen 校对制作、字幕包装和 YouTube 私密上传。保留各自的剪辑软件，机械操作由包内脚本执行，审核与账号授权由本人完成。

**当前版本：v2.3.22-rc.10（预发布试用版）。** 另一台 Mac 尚未实测；Windows 本版未验收。没有承诺无人值守的完整生产流程。

## 能做什么

| 环节 | 当前能力 | 需要本人做什么 |
| --- | --- | --- |
| 批量切片 | 文件夹批量扫描、全片覆盖、多条30–45秒切片、数量与并行控制、保留原片 | 给素材路径和要求；初期播放检查，动作仍需视觉审核 |
| 选文与译审 | 主题选择、来源与上下文记录、多语种逐项执行、Google盲回译、Gemini独立校对 | 配置本人模型服务，确认原文与每版译稿 |
| 本地审核 | 逐条审核页面、意见与状态记录、版本核对、成片本地播放 | 实际阅读/播放后明确决定；不会替你批准 |
| HeyGen | 上传视频和目标字幕、Proofread校对、生成与下载脚本 | 本人账号、逐任务费用授权、网页试听和最终生成确认 |
| 字幕与发布资料 | 六套内置字幕模板、自动评估模板、位置与重点色；标题简介起草 | 按实际音频对齐并听审，审核模板与发布资料 |
| YouTube | 授权频道核对、私密上传、处理状态检查 | 提供本人OAuth配置，确认成片及标题简介 |

## 还不能当作已验收能力

- Notion：可选只读预检和已登记块收据适配已附带；通用页面注册、真人批准与生产启用未验收，本地 HTML 不依赖它。
- 审完旧版自动打开新版审核页尚未完成，当前手动打开链接。
- 开头钩子预览可能过长，未保证约3秒或听感合格，不能直接当批准成片。
- 没有自动检查版本或自动保留配置更新器；按 [升级说明](UPGRADE.md) 手动更新完整包。
- 机器预筛不能保证人物动作全部合格；检索不能保证找到所有语义相关资料；翻译不能替代人工审定。
- 另一台 Mac 与 Windows 尚未验收；本轮未重跑真实平台全链路。

## 老用户须注意

**不升级不受影响。** 升级后，新建/返修译稿需要补充 Google Cloud Translation API 配置，旧 Gemini-only 配置会停止并提示；不会静默替换提供方。其他独立步骤不因此停用。

字幕默认自动选模板且位置有调整；要保持旧样式，明确指定旧模板与位置（`--shift-up 0`）。历史批准不自动迁移到新审核轮次。个人配置、素材和产物保留在包外，更新后在最终安装位置重建依赖并运行 `project sync`。

六套模板、字体和许可随包提供，无需私有GitHub权限。统一交付清单 `delivery` 按需使用；不用清单仍须保留实际任务的批准与质检记录。
